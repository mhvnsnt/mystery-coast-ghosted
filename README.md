# Mystery Coast: Ghosted

**Network:** TRIPPEDD

A mystery-solving team too lazy to solve mysteries. Scooby-Doo meets Space Ghost Coast to Coast meets Aqua Teen Hunger Force.

## Template

Animation style pulls from the Hanna-Barbera production template:

**[mhvnsnt/cn-gigaleak-scooby-doo-mystery-inc](https://github.com/mhvnsnt/cn-gigaleak-scooby-doo-mystery-inc)**

This repo starts from that template and diverges as the show develops its own identity.

## Concept

They're not heroes. They're lazy idiots who accidentally solve mysteries while bullshitting around like the ATHF crew. The mystery is incidental — they'd rather be doing anything else.

See [SHOW-BIBLE.md](SHOW-BIBLE.md) for the full concept.
